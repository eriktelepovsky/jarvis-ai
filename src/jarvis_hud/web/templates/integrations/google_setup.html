Set up Google

About 10 minutes · free

Jarvis runs on your own server, so it uses your own Google Cloud project instead of a shared one. Your data goes only between Google and your Jarvis. The project is free for personal use.

  1. Create a project

    Open Google Cloud Console → New project, name it e.g. Jarvis and create it. Make sure the new project is selected at the top of the console in the next steps.

  2. Enable the APIs

    Open each link and click Enable:

    • Gmail API
    • Google Calendar API
    • YouTube Data API v3 (for new videos from your subscriptions)

  3. Configure the consent screen

    Open Google Auth Platform and click Get started. Enter the app name Jarvis and your email. For Audience, choose External (or Internal if you use Google Workspace and only connect accounts from your organization).

  4. Publish the app

    For an External app, go to Audience and click Publish app. While an app is in Testing, Google signs it out every 7 days. Publishing does not make anything public and does not require Google's review for your own use.

  5. Create an OAuth client

    Go to Clients → Create client. Choose Web application and name it Jarvis. Leave Authorized JavaScript origins empty. Under Authorized redirect URIs, click Add URI and paste:
