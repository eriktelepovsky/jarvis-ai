Daily brief

myOrb asks Claude, Anthropic's AI, to write your daily brief from today's calendar, the subjects and senders of your latest unread emails, and your to-do list. That information is sent to Anthropic's API with your own API key each time a brief is written: once a day at the time below, and when you ask for a new one.

Create an API key in the Anthropic Console. A brief costs about 1–3 cents with Sonnet, a few cents with Opus and well under a cent with Haiku.

Only for an API key created for the whole organization rather than in a workspace. Find the ID in the Console under Settings → Workspaces.
