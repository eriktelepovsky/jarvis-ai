1. Open Atlassian account → API tokens and click Create API token. Name it myOrb.
  2. Paste it below with your Atlassian account email and the Jira address you open in the browser (e.g. https://mycompany.atlassian.net).
  3. For more workspaces (e.g. development and support on different sites), connect each one. One token works for all sites of your account.

myOrb only reads the issues assigned to you that are not done.
