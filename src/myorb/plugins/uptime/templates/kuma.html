1. In your Uptime Kuma, open Settings → API Keys, click Add API Key, name it myOrb and copy the key.
  2. Paste it below with Kuma's address, the one you open it at.

myOrb reads the state of Kuma's monitors from its /metrics every minute and shows them with its own monitors, with their outages and certificates. Kuma keeps checking them; myOrb does not check them again. Monitors added or removed in Kuma come and go here too.
