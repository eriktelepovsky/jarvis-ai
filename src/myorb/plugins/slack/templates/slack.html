1. Open Slack API → Create New App, choose From a manifest and pick your workspace.
  2. Paste this manifest (JSON) and create the app. It asks to search messages you can see (search:read) and to see which of your direct and group messages are unread (im:read, mpim:read). It cannot send anything. 
    {{ slack_manifest() }}
  3. Click Install to Workspace and allow it. Your workspace may need an admin to approve the app.
  4. Under OAuth & Permissions, copy the User OAuth Token (it starts with xoxp-) and paste it below.

For more workspaces, install the app in each one and connect each token.

Connected before myOrb showed direct messages? Open your app, paste the manifest under App Manifest, reinstall the app and connect the new token.
