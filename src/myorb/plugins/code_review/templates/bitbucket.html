1. Open Atlassian account → API tokens and choose Create API token with scopes.
  2. Name it myOrb, choose the Bitbucket app and the read scopes for user, workspace, repository and pull request (read:user:bitbucket, read:workspace:bitbucket, read:repository:bitbucket, read:pullrequest:bitbucket).
  3. Paste the token below with your Atlassian account email and the workspace. Each workspace is a separate connection.

Bitbucket has no search for pull requests waiting for your review, so myOrb checks the 30 most recently updated repositories of the workspace.
