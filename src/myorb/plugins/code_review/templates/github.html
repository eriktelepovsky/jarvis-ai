1. Open GitHub → New personal access token (classic). The link preselects the repo and read:org scopes, which private repositories and organization reviews need.
  2. Set an expiration you are comfortable with and click Generate token.
  3. Copy the token and paste it below. myOrb only reads; it never comments or merges.

A fine-grained token works too: give it access to the repositories and read access to Pull requests, Commit statuses and Checks.
